# magpie-plugins

自用 [magpie](https://usemagpie.ai) 插件合集。

## 插件

| 插件 | 说明 |
| --- | --- |
| [auto-checkin](packages/auto-checkin) | 签到管家：把 magpie 里配置过的 new-api / sub2api 中转站每天自动签一遍，签不了的逐条说明原因 |

## 安装

```sh
magpie plugin add github:CallMeKingsley97/magpie-plugins/packages/<插件名>
```

也可以克隆后用本地路径安装：`magpie plugin add ./packages/<插件名>`。
